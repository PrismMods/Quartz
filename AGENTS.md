# Agent entry point

Read the repo rules in `agents/` before working. They override your defaults.

- `agents/project.md` — read first: project map, conventions, build and test commands.
- `agents/commits.md` — before any commit or push (format, splitting, no AI co-author lines).
- `agents/i18n.md` — before touching any user-facing string or Lang JSON.
- `agents/release.md` — before cutting a release.
- `agents/docs.md` — docs site sync after a release.
